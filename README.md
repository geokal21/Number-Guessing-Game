# 🎲 Number Guessing Game (Python)

Ένα απλό παιχνίδι γραμμής εντολών (CLI) όπου ο υπολογιστής διαλέγει έναν τυχαίο αριθμό και ο παίκτης προσπαθεί να τον μαντέψει.  

---

## 🚀 Χαρακτηριστικά
- Ο υπολογιστής επιλέγει τυχαίο αριθμό από 1 έως 100.
- Ο παίκτης δίνει προβλέψεις μέχρι να βρει τον σωστό αριθμό.
- Feedback σε κάθε προσπάθεια ("Πολύ μικρός", "Πολύ μεγάλος").
- Εμφανίζει τον αριθμό προσπαθειών όταν βρεθεί η λύση.
- Έλεγχος για μη έγκυρη είσοδο (π.χ. αν δεν δοθεί αριθμός).

---

## 🛠️ Εγκατάσταση & Εκτέλεση

### 1. Κλώνος του repo
```bash
git clone https://github.com/username/number-guessing-game.git
cd number-guessing-game
```
### 2. Εκτέλεση με Python
```
python game.py
```

ή (σε ορισμένα συστήματα):
```
python3 game.py
```

### 3. Δημιουργία .exe (Windows)
```
pip install pyinstaller
pyinstaller --onefile game.py
```
Το εκτελέσιμο αρχείο θα δημιουργηθεί στον φάκελο dist.
